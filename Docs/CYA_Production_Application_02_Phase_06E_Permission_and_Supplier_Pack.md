# Part D — Supplier quote request — sendable brief

## Subject: Quote request — Corporate Yoga Australia Workday, Interrupted still + motion pilot

Corporate Yoga Australia is preparing a one-day workplace photography and motion pilot in Brisbane to create a modular rights-cleared library for its new website and ongoing marketing.

Our creative idea is **Workday, Interrupted**. The core sequence is:

**WORK CONTEXT → NOTICE → USEFUL ACTION → RETURN**

We want documentary-style working life rather than generic corporate-wellness or yoga-studio imagery.

### Proposed production

- one full working day;
- one genuine Brisbane workplace;
- approximately 6–8 workplace participants;
- one CYA facilitator;
- one remote participant for a hybrid-work sequence;
- desk, meeting-room, breakout and transition areas;
- simultaneous or closely paired photography and motion capture.

### Priority content

1. Homepage expressive sequence: ordinary work → small human signal → brief useful action → return to work.
2. Human Signal detail library: hands, screens, posture shifts, listening, note-taking and transitions.
3. Hybrid-work sequence: in-room and remote participants in one credible scene.
4. Varied participation: seated, standing, adapting or simply listening rather than synchronised performance.
5. Shared workshop/Lunch & Learn coverage where time allows.

### Photography deliverables requested

Please quote for approximately:

- 50–70 final edited stills;
- 10+ strong hero/expressive candidates;
- full-resolution masters/finals;
- landscape 3:2 / 16:9-safe coverage;
- portrait 4:5 and dedicated 9:16-safe priority compositions;
- web-ready derivatives or a clear licence for CYA to create derivatives.

### Motion deliverables requested

Please quote for approximately:

- 4K capture;
- 20–30 clean graded modular clips of 6–12 seconds;
- landscape and dedicated vertical priority takes;
- one complete 15–25 second four-beat sequence;
- 3–5 additional modular short sequences;
- clean versions without baked-in text/music.

### Production style

Please assume:

- natural workplace lighting supplemented only as needed;
- real work tasks and restrained direction;
- no synchronised stretching rows;
- no staged laughter/applause;
- no activewear/yoga-studio aesthetic;
- no generic wellness props;
- strong attention to confidential screens/documents;
- crop flexibility and natural skin tones;
- still and motion coverage of the same key moments.

### Usage/licence

Please state clearly in the quote:

- the commercial usage licence granted to Corporate Yoga Australia;
- territory and duration;
- whether paid media is included;
- whether CYA may crop, resize, grade and create derivatives;
- whether final high-resolution files are included;
- availability/cost of selected RAW/original camera files if required;
- your portfolio/self-promotional usage rights;
- third-party music/stock/licence terms for any edited video;
- storage/archive period;
- confirmation that CYA material will not be used for AI/model training without written approval.

### Please itemise

- pre-production;
- shoot crew/day rates;
- equipment/lighting/audio;
- travel/parking;
- photography post-production;
- motion editing/colour/audio;
- revision rounds;
- licensing/usage fees if separate;
- additional location/day cost;
- overtime;
- GST;
- expected turnaround.

### Please also confirm

- public liability / professional insurance appropriate to workplace production;
- experience filming in active workplaces;
- process for participant/model releases;
- process for secure file transfer and storage;
- earliest suitable dates.

# Part E — Quote comparison scorecard

Score each supplier from **1–5** for each criterion.

| Criterion | Weight | What good looks like |
|---|---:|---|
| Documentary workplace sensibility | 20% | Natural observation; work remains visible; avoids generic wellness styling |
| Still + motion quality | 15% | Both disciplines are genuinely strong rather than one being an add-on |
| Understanding of the brief | 15% | Can explain how they will capture work → notice → action → return |
| Rights/licensing clarity | 15% | Broad, unambiguous CYA commercial rights; no hidden usage surprises |
| Crop/multi-format planning | 10% | Plans landscape, portrait and vertical deliberately at capture |
| Workplace/confidentiality discipline | 10% | Clear approach to screens, staff consent, site rules and sensitive information |
| Production efficiency | 5% | Can obtain priority shots without overshooting generic content |
| Post-production/delivery | 5% | Clear selects, consistent grade, organised delivery and turnaround |
| Cost/value | 5% | Appropriate cost for useful long-term library, not merely cheapest day rate |

**Recommended decision rule:** do not select a lower-priced supplier if documentary sensibility, rights clarity or still/motion capability scores below 3/5.
