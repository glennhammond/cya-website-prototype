# CYA — Phase 11.5 First 30-Day Search Decision Queue v1.0

**Prepared:** 26 August 2026  
**Activates:** production migration  
**Purpose:** prevent reactive post-launch SEO changes while identifying the first evidence-backed optimisation opportunities.

## Rule zero

The first 30 days are a **migration observation window**, not a content-production sprint.

Do not change URLs, page ownership, major headings or search architecture because of daily ranking noise. Changes require a meaningful signal plus a plausible cause.

## Queue A — Protect immediately

### A1. Home / `corporate yoga`

**Ground Zero:** current Ahrefs Rank Tracker #1; Home is the intended canonical owner.

Watch:
- ranking remains materially strong;
- GSC impressions/clicks persist;
- Home remains Google's preferred URL;
- CTR relative to pre-launch baseline.

Action threshold:
- investigate if Home loses material visibility for 7+ days, or Google begins preferring an unintended page.

Do not:
- force `corporate yoga` onto `/workplace-yoga`;
- weaken Home to manufacture specialist-page movement.

### A2. Existing editorial authority

Protect:
- `body check in` — Ground Zero #8 on the Check-In-With-Yourself Insight;
- `yoga at work` — Ground Zero #8 on the Yoga-at-Work Insight.

Action threshold:
- investigate only if protected Insights disappear materially after migration or their canonical/indexation state is wrong.

## Queue B — Canonical consolidation tests

### B1. `workplace yoga`

**Ground Zero:** #2, currently ranking Home.

Desired post-launch behaviour:
- Home stays strong for broad corporate-yoga authority;
- `/workplace-yoga` increasingly becomes the preferred ranking URL for specialist workplace-yoga intent.

Success is not simply “position rises”. A stable position with better ranking-URL alignment is a structural win.

Review at +7, +14 and +28 days.

### B2. Program procurement cluster

Primary page: `/workplace-wellbeing-programs`.

Ground Zero tracked visibility is effectively zero for:
- corporate wellness programs — 500/mo;
- workplace wellbeing programs — 250/mo;
- corporate wellbeing programs — 200/mo;
- employee wellbeing programs — 150/mo;
- workplace wellness programs — 150/mo.

First positive signal:
- impressions in GSC, even before page-one rankings;
- Ahrefs position enters top 50/20;
- correct canonical page is ranking across several synonyms.

Do not create separate pages for each synonym.

### B3. Workplace Pilates

Primary page: `/workplace-pilates`.

Ground Zero: no tracked ranking for `corporate Pilates`, `corporate Pilates classes` or `workplace Pilates`.

First positive signal:
- any meaningful GSC impressions to `/workplace-pilates`;
- entry into top 50/20 for direct Pilates terms;
- no cannibalisation problem with Home.

Hold major optimisation until at least +14 days unless indexing/canonical behaviour is wrong.

### B4. Mindfulness & Meditation

Primary page: `/meditation-mindfulness`.

Ground Zero:
- `workplace meditation` #19;
- `corporate mindfulness workshops` #26;
- related mindfulness terms mostly unranked.

First optimisation candidate if:
- page remains 11–30 for a useful term after 2–4 weeks;
- impressions are present but CTR/relevance is weak;
- supporting Insights can provide stronger contextual internal authority.

## Queue C — CTR opportunities

Use native GSC, not Ahrefs traffic estimates.

Potential optimisation becomes eligible when:
- a page has meaningful impressions;
- average position is roughly 1–10/15;
- CTR is persistently weak relative to the query intent;
- ranking URL is already the correct canonical page.

Only then consider title/meta/search-snippet refinement.

Priority historical watch item: `corporate yoga`, where the pre-launch GSC baseline showed substantial impressions and clear click-capture headroom.

Do not rewrite titles during the first few migration days merely because current CTR is low.

## Queue E — What we explicitly do NOT do in the first 30 days

- no city doorway pages;
- no separate synonym pages for workplace/corporate/employee wellbeing programs;
- no bulk AI-written Insights to “support SEO”;
- no paid backlink packages or directory campaigns;
- no exact-match anchor manipulation;
- no major architecture changes based on daily Rank Tracker movements;
- no publishing Case Studies without evidence/permission;
- no SaaS/platform-led repositioning of Wellbeing Studio because of search terminology.

## Decision cadence

### +24h
Technical/indexing safety only.

### +3d
Canonical/indexation and obvious loss checks.

### +7d
Early ranking URL alignment; no broad optimisation.

### +14d
First useful performance comparison; identify contained opportunities.

### +28d
First optimisation decisions may be approved where evidence is sufficient.

## First likely optimisation pathways — only if evidence supports them

1. CTR/meta refinement on high-impression correct-canonical pages.
2. Contextual internal-link strengthening from protected Insights to service pages.
3. Program page refinement if procurement terms show impressions but weak relevance/CTR.
4. Mindfulness refinement if the existing 11–30 positions persist.
5. Authority reclamation from high-value historical/noncanonical backlinks.
6. Strengthen genuinely referenceable CYA assets rather than manufacture link bait.

**Decision principle:** protect first, observe second, optimise third. The rebuild should be allowed to establish its search signals before we start moving the furniture again.
