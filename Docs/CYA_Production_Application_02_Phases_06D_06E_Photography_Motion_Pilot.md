# CYA Production Application 02 — Photography & Motion Pilot

**Phases:** 06D Photography Gap Map + Pilot Brief / 06E Pilot Shoot Readiness  
**Status:** EXECUTABLE PILOT BRIEF  
**Date:** 2 September 2026  
**Creative authority:** Workday, Interrupted  
**Behaviour:** WORK CONTEXT → NOTICE → USEFUL ACTION → RETURN

---

## 1. Production objective

Create the smallest rights-cleared still-and-motion library that materially improves the launch-critical CYA website and establishes a repeatable capture method for future campaigns and client activation.

The pilot is not a generic corporate-wellness shoot and not a yoga-class shoot. It should document **working life with a useful interruption inside it**.

The resulting library must make it possible to show:

1. recognisable working context before wellbeing appears;
2. small human signals that make the moment feel observed rather than staged;
3. a proportionate action that fits the workplace;
4. a credible return to work, conversation, concentration or movement through the day.

---

This means the first shoot should **fill structural gaps**, not recreate categories already adequately represented.

### Important rights boundary

Publication approval for an image is not proof of a specific client relationship, testimonial, result, credential or case-study claim. Named-client use must retain its own factual and permission trail.

The currently implemented homepage hero file is not referenced through the governed `media.ts` register. Before launch it should either:

- be explicitly entered into the governed register with its rights evidence; or
- be replaced by a governed existing image or the pilot hero asset.

## 4. Minimum Viable Shoot — recommended production model

### One full working day · one genuine Brisbane workplace · still + motion

**Recommended crew**

- 1 dedicated photographer;
- 1 dedicated videographer / motion shooter;
- CYA creative/art direction and shot governance;
- 1 CYA facilitator;
- 6–8 consenting workplace participants;
- 1 consenting remote participant for hybrid sequences;
- client/location contact available for access and approvals.

A two-person capture crew is recommended because the most useful moments are small and transient. It allows stills and motion to record the same genuine action without repeatedly restaging every beat.

### Coverage zones

Use one workplace with at least four believable zones:

1. **Desk / concentration zone** — screens, keyboard, notebook, chair, ordinary individual work;
2. **Meeting / collaboration room** — conversation, listening, workshop, hybrid screen;
3. **Breakout / kitchen / circulation zone** — natural transitions between work moments;
4. **Quiet edge of workplace** — short individual reset without becoming a wellness-studio scene.

A second industrial/operational location is valuable later, but is not required for the first minimum viable day because existing governed imagery already covers that context.

## 5. Priority shot list mapped to page placements

### Sequence A — Home hero: “The day was already full”

**Page placement:** Home hero / primary Workday Window  
**People:** 1–2 workers + optional facilitator  
**Context:** genuine desk or meeting-room work

Capture the same believable moment as a still-and-motion sequence:

1. **WORK CONTEXT** — person actively reading, typing, reviewing a document or listening in a meeting;
2. **NOTICE** — small shift in posture, hand to shoulder, eyes leaving screen, breath or pause; no exaggerated pain or stress acting;
3. **USEFUL ACTION** — brief seated/standing shoulder mobility, breathing cue or posture reset; facilitator can enter only where credible;
4. **RETURN** — hands back to keyboard, eyes back to colleague/screen, walking back into meeting, notebook reopened.

**Still requirements**

- landscape 3:2 master;
- additional landscape 16:9-safe composition;
- portrait 4:5 master;
- vertical 9:16-safe alternative;
- square-safe crop;
- clean subject-right and subject-centre variations;
- enough negative/low-detail area for flexible crop or copy placement even where the website does not overlay copy.

**Motion requirements**

- 4K landscape 16:9;
- dedicated 9:16 takes rather than relying only on crop;
- 6–12 second clean clips for each beat;
- one continuous 15–25 second four-beat sequence;
- static or restrained camera movement; no wellness-reel choreography.

---

### Sequence B — Human Signal library

**Page placements:** Home, Programs, Workshops, social/client activation derivatives  
**People:** 1–4 workers, captured naturally

Capture:

- hand leaving mouse or keyboard;
- hand on notebook / pen during listening;
- shoulder or wrist movement beside a laptop;
- face listening rather than posing;
- eyes moving from screen to colleague;
- hands around ordinary tea/coffee/water, not wellness props;
- phone face-down beside work materials;
- chair adjustment / feet repositioning;
- walking between desk and meeting room;
- doorway / lift / corridor transition;
- remote colleague on screen with in-room participant foreground;
- return to typing, writing, talking or walking.

**Crop rule:** every detail should retain enough workplace evidence that it does not become an anonymous wellness close-up.

---

### Sequence C — Programs: hybrid working life

**Page placement:** Workplace Wellbeing Programs — delivery context  
**People:** 3–4 in room + 1 remote participant  
**Context:** actual meeting room with ordinary AV screen

Capture:

1. normal hybrid meeting/work context;
2. a short facilitated pause that both in-room and remote people can follow;
3. different participation levels — no compulsory synchronised movement;
4. return to discussion/work with the remote person still visibly included.

**Critical composition:** in-room people and remote screen must both remain legible in the same landscape frame without exposing confidential UI, names or client information.

---

### Sequence D — Programs: participation without performance

**Page placement:** Programs participation section  
**People:** 3–6  
**Context:** desks / meeting area

Capture individuals making different proportionate choices:

- one seated;
- one standing;
- one observing/listening;
- one adapting a movement;
- facilitator demonstrating rather than correcting bodies into uniform positions.

The aim is to prove **choice, accessibility and workplace fit**, not flexibility or physical achievement.

---

### Sequence E — Workshop / Lunch & Learn shared coverage

**Page placement:** Workplace Wellbeing Workshops; secondary because an existing governed hero now works  
**People:** facilitator/expert + 4–8 participants

Capture:

- facilitator speaking with audience visible;
- participant listening;
- participant asking a question;
- hands taking notes;
- two colleagues exchanging a brief comment;
- useful takeaway/resource being referenced;
- end-of-session transition back to work.

Avoid distant podium imagery, unreadable projection screens and staged applause/laughter.

## 6. Composition and crop specification

### Photography

Capture each P0 setup in:

- **3:2 landscape** — primary website/editorial master;
- **4:5 portrait** — social/editorial portrait master;
- **1:1-safe** — not necessarily a separate frame if the master has sufficient crop latitude;
- **9:16-safe** — dedicated vertical composition for high-value scenes;
- **wide copy-safe variant** — subject positioned left and right in separate takes where practicable.

Preferred source resolution: modern full-resolution RAW capture, with final hero derivatives comfortably exceeding 2400 px on the long edge.

### Motion

Preferred capture baseline:

- 4K UHD;
- 25 fps for normal-speed Australian workplace capture;
- shutter around 1/50 where technically appropriate to reduce 50 Hz lighting flicker;
- additional slow-motion only when there is a clear editorial need;
- record clean ambient room tone even if website motion will ultimately be muted;
- capture both 16:9 and dedicated 9:16 for P0 sequences.

The photographer/videographer may adjust technical settings for the actual lighting and camera system; consistent, natural colour and skin tone matter more than a prescribed camera profile.

## 7. People, casting and workplace truth

### Participant mix

Aim for a credible real-workplace mix rather than demographic tokenism:

- varied ages and career stages;
- mixed genders;
- varied body types;
- different work roles where the workplace genuinely contains them;
- seated and standing participation;
- at least one person who does not perform the same movement as everyone else;
- remote participation where real and consented.

### Direction to participants

Use real tasks or simple prompts:

- “Continue what you were doing.”
- “Talk through the actual agenda.”
- “Listen to the person opposite you.”
- “Take the short reset in the way that feels useful.”
- “Go back to the document/meeting afterwards.”

Do not ask people to simulate exhaustion, perform exaggerated relief, laugh on command, form yoga lines or hold difficult poses.

## 8. Wardrobe, props and environment

### Wardrobe

- participants: what they would credibly wear for that workplace and day;
- facilitator: professional, approachable and movement-capable without reading as gym/yoga-studio uniform;
- avoid coordinated colour dressing, matching activewear, conspicuous wellness branding and wardrobe that makes the room look cast.

### Props

Use ordinary work objects already present:

- laptops and monitors;
- notebooks and pens;
- mugs/water bottles;
- headsets;
- meeting-room AV;
- phones;
- workplace chairs and tables.

Do not add yoga mats, candles, incense, plants or props merely to make the scene look “wellness”. A mat may appear only where the actual service and room genuinely require one.

### Confidentiality sweep

Before every setup check:

- screens and whiteboards;
- employee/client names;
- personal data;
- internal dashboards;
- documents on desks;
- access passes;
- visible client/customer information;
- branded materials that could imply an unapproved endorsement.

Use dummy screen content where needed.

## 9. Rights, consent and permission package

No asset enters the governed library until all applicable permissions are recorded.

### A. Participant release

Each identifiable participant should sign a written release covering:

- CYA commercial marketing use;
- website and Wellbeing Studio marketing surfaces;
- organic and paid social;
- email, proposals, presentations, client-activation materials and print;
- still and moving image;
- crops, resizing, colour grading, captions and derivative formats;
- broad geographic use and a clearly stated duration;
- use by CYA's production/marketing suppliers on CYA's behalf;
- confirmation that participation was voluntary.

The release should also make clear that CYA will not deliberately use the person's image in a materially misleading, defamatory or sensitive/clinical context unrelated to what was agreed.

### B. Client / employer permission

Written permission should cover:

- filming/photography at the site;
- permitted rooms and times;
- whether the client name/logo may be visible;
- whether the client may be identified in captions/case studies;
- approval responsibility for confidential/sensitive details;
- WHS/site induction requirements;
- any restrictions on paid advertising or third-party use.

**Site permission does not equal client endorsement permission.** Treat the two separately.

### C. Location / property permission

If a landlord, coworking venue or third-party property controls photography, obtain its location release in addition to the client/employer permission.

### D. Remote participant permission

Remote people appearing on screens require the same identifiable-person marketing consent as in-room participants. Do not rely on ordinary meeting attendance as marketing consent.

### E. Photographer/videographer agreement

The production contract should give Corporate Yoga Australia a sufficiently broad commercial licence to the commissioned deliverables for the intended channels, territories, duration, crops and derivatives. Confirm explicitly:

- ownership/licence of final files;
- whether selected RAW/original camera files can be supplied or archived;
- portfolio/self-promotion rights of the creator;
- music/stock/font/third-party licence terms in edited motion;
- model/location release responsibility;
- storage/archive duration;
- permitted AI/model-training use — recommended **not permitted** without separate written CYA approval.

Obtain legal review of the final release templates where appropriate; this document is a production checklist, not legal advice.

## 12. File naming and metadata standard

### Master naming

`CYA_YYYYMMDD_PILOT_[LOCATION]_[SCENE]_[BEAT]_[SUBJECT]_[ORIENTATION]_[TAKE]_v01.ext`

Examples:

- `CYA_202609XX_PILOT_CLIENT01_DESK_WORK_01_LAND_T01_v01.cr3`
- `CYA_202609XX_PILOT_CLIENT01_DESK_NOTICE_01_VERT_T02_v01.mov`
- `CYA_202609XX_PILOT_CLIENT01_HYBRID_RETURN_GROUP_LAND_T03_v01.mov`

### Rights metadata required before publication

Record for each governed master/select:

- asset ID;
- capture date;
- creator;
- location;
- scene/sequence/beat;
- participant release IDs;
- client/location release ID;
- usage territory/duration;
- expiry/review date if any;
- client-logo permission status;
- paid-media permission status;
- sensitive-context restrictions;
- source master location;
- crop/focal guidance;
- mapped website placement(s);
- alt-text draft;
- rights status: `pending | approved | restricted | expired`.

## 13. Ingestion and approval workflow

1. **Ingest** — two verified copies of camera masters before cards are erased.
2. **Technical reject** — focus, exposure, flicker, duplicates, accidental confidential information.
3. **Rights reconciliation** — attach participant/site/client release IDs before creative approval.
4. **Contact sheet** — organise by Sequence A–E and WORK / NOTICE / ACTION / RETURN beat.
5. **Creative select** — select for meaning and crop flexibility, not just prettiest frame.
6. **Confidentiality/client check** — only where client/site agreement requires it.
7. **CYA final approval** — `approved`, `restricted` or `reject` recorded.
8. **Derivatives** — web, social, portrait, square and vertical crops generated from approved masters.
9. **Website mapping** — ingest governed assets through `content/media.ts` rather than bypassing the register.
10. **Archive** — masters, deliverables, releases and metadata retained together with a clear rights review process.

## 15. Minimum Viable Shoot recommendation

Proceed to supplier briefing on the basis of **Option B**:

> **One full working day in one genuine Brisbane workplace, 6–8 real consenting participants, one facilitator, one remote participant, dedicated still + motion coverage, with Home Sequence A and hybrid Sequence C treated as non-negotiable captures.**

Do not spend the first pilot budget recreating generic group movement already present in the governed library. Use the day to create the missing workday grammar: screens, concentration, noticing, small useful actions, hybrid inclusion, transitions and credible return to work.

A later client-specific micro-shoot should resolve the Cromwell proof image independently because that asset must be genuine client evidence, not a generic substitute.

## 16. Photographer / videographer briefing — sendable summary

Corporate Yoga Australia is creating a documentary-style still-and-motion library for its website and marketing. The governing creative idea is **Workday, Interrupted**.

We do not want generic wellness imagery. Every useful frame should begin in recognisable working life and show a proportionate wellbeing action inside it. The central sequence is:

**WORK CONTEXT → NOTICE → USEFUL ACTION → RETURN**

Please prioritise:

- real desks, meetings, screens, conversation and concentration;
- small human signals rather than performance;
- genuine workplace clothing and environments;
- different levels of participation;
- hands, posture, listening and transitions;
- hybrid work with in-room and remote people in the same story;
- still and motion versions of the same priority moments;
- landscape, portrait and dedicated vertical-safe capture;
- restrained documentary direction;
- clean return-to-work moments.

Please avoid:

- yoga-studio visual language;
- generic wellness wardrobe;
- synchronised stretching lines;
- staged laughter or applause;
- difficult poses or flexibility-as-proof;
- candles, mats or wellness props unless genuinely required;
- images detached from working life;
- identifiable confidential screen/document content;
- any use of captured material for AI/model training without separate written CYA approval.

The deliverable is a **modular, rights-cleared workday library**, not a glossy one-off brand film.
