# CYA — Phase 11.5 Authority Action Queue

**Prepared:** 26 August 2026  
**Status:** OPERATOR READY / OUTREACH HELD UNTIL MIGRATION SAFETY GATE  
**Market:** Australia

## Purpose

Turn the Phase 11.5 authority strategy into a finite operating queue based on live CYA evidence.

The queue deliberately separates:

1. authority CYA already earned and must protect;
2. direct-link reclamation opportunities after migration stabilises;
3. genuine relationship/editorial expansion opportunities;
4. backlink noise that should not consume time.

No broad outreach begins before the +14 day migration safety review is satisfactory.

## Queue rules

- A link is valuable because it is credible, relevant and durable, not because its DR is high.
- Do not ask a publisher to change a link during migration turbulence unless the current destination is genuinely broken.
- Prefer a direct canonical link after migration, but a healthy one-hop 301 is not an emergency.
- Never offer payment, reciprocal-link quotas, exact-match anchor demands or fabricated editorial reasons.
- Do not attempt to reclaim spam, hacked or irrelevant directory links.
- Every outreach action should still make sense if Google did not exist.

3. experts participating in substantive CYA experiences;
4. useful resource/editorial contribution;
5. selective PR only around genuine stories/assets.

## Success criteria

The queue is working when CYA:

- keeps its strongest existing references through migration;
- reduces unnecessary redirect hops on quality backlinks;
- earns a small number of highly relevant new references from real relationships;
- sees referral/search value from those relationships;
- does not waste effort manufacturing backlink volume.

---

**Operating principle:** protect first, reclaim second, earn third. Never mistake backlink inventory for business authority.
