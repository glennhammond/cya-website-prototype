## Activation sequence

### Before DNS cutover — current state

Allowed:

- freeze baselines;
- prepare monitoring queries;
- classify existing authority;
- prepare partner/expert material;
- research credible authority ecosystems;
- preserve launch architecture.

Not allowed:

- broad backlink outreach;
- post-launch optimisation changes;
- reactive metadata/content edits based on pre-cutover Rank Tracker movement;
- new thin service/location pages;
- changes to the frozen launch runtime without a genuine production blocker.

### Launch to +14 days

Priority is **migration protection**, not growth activity.

Do:

- technical verification;
- GSC/indexation monitoring;
- Rank Tracker observation;
- quality referring-domain preservation checks;
- direct verification of the strongest existing external references.

Do not start broad authority acquisition.

### +14 day safety review

If migration safety is satisfactory:

1. reclaim high-quality obsolete/non-canonical external destinations where practical;
2. validate Tier A authority-gap candidates for genuine fit;
3. identify real warm client/expert/venue/partner opportunities;
4. select the first 2–3 link-worthy CYA assets to strengthen;
5. draft contained relationship outreach only after fit is established.

### +28 days onward

Use GSC + Rank Tracker + Site Audit + referral/commercial signals to choose **Protect / Improve / Investigate / Hold**.

Do not create an SEO activity backlog detached from CYA's business/product evidence.
